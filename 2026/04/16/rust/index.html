cargo

项目创建

对于一个新项目的创建，可以使用 cargo new "项目名称" 来完成

对于一个不是用cargo创建的项目，也可以通过在项目下新建一个src文件夹，并将所有的源代码放入该文件夹下，并执行 cargo init 来将项目初始化成cargo项目。

项目构建

对于由cargo创建或初始化的项目，可以通过 cargo build 进行项目的编译，并通过 ./target/debug/"项目名称" 来进行运行，亦或者通过 cargo run 直接完成项目的构建和运行；

对于较大项目，其编译成本较高，可以先通过cargo check 来进行错误检查，再修改完错误后，再进行编译；

对于发行项目的构建，可以添加 --release 参数（cargo build --release）来对其进行一些优化下的编译，其最终结果将会存储在 target/release 文件夹下。

数据类型

标量类型

  • 整型
    • 有符号
      • i8、i16、i32、i64、i128
      • isize(取决于架构)
    • 无符号
      • u8、u16、u32、u64、u128
      • usize(取决于架构)
  • 浮点型
    • IEEE-754标准
    • f32、f64
  • 布尔类型
    • bool
    • true、false
  • 字符类型
    • char
    • 使用Unicode

复合类型

  • 元组
    • let tup: (i32, f64, u8) = (500, 6.4, 1);
    • 可以使用模式匹配来进行解构：let (x,y,z) = tup;
    • 也可以使用 . 来直接访问：let five_hundred = x.0; ,即five_hundred的值为x的第一个元素
  • 数组
    • 定义 let a = [1, 2, 3, 4, 5];
    • let a :[i32; 5] = [1, 2, 3, 4, 5]
    • let a = [3; 5]; => let a = [5, 5, 5, 5, 5]
    • 访问与c语言相同
    • 数据空间在栈中，大小不可变
