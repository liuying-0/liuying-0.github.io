语法介绍

RISC-V汇编语句由3部分组成

label（标号）：GNU 汇编中，任何以冒号结尾的标识符都被认为是一个标号

operation（操作）：又以下多种类型

  • instruction（指令）：直接对应二进制机器指令的字符串
  • pseudo-instruction（伪指令）：为了提高编程效率，由一条或多条指令封装而成
  • directive（指示/伪操作）：通过类似指令的形式（以”.“开头），通知汇编器如何控制代码的产生，不对应具体的指令
  • macro（宏）：采用.macro/.endm自定义的宏

comment（注释）：与c语言注释类似，常用”#“开头到其后第一个换行符

指令总览

在后续的指令中，都基于 RV32I 的ISA架构，共有32个通用寄存器（$x_0 $~$ x_{31}$），Hart在执行算术逻辑运算时所操作的数据必须来自于寄存器，对于访存必须使用专用的访存指令，且其内存采用小端存储方式。

其指令编码分为六类，分别是：

  • R-type（Register）：每条指令中有三个fields，用于指定3个寄存器参数
  • I-type（Immediate）：每条指令中带有两个寄存器参数和一个立即数参数
  • S-type（Store）：每条指令带有两个寄存器参数和一个立即数参数
  • B-type（Branch）：每条指令带有两个寄存器参数和一个立即数参数（恒为2的倍数）
  • U-type（Upper）：每条指令带有一个寄存器参数和一个立即数参数
  • J-type（Jump）：每条指令带有一个寄存器参数和一个立即数参数

从其功能上划分，可以分为六大类，即：

  • 算术运算指令
  • 逻辑运算指令
  • 移位运算指令
  • 内存读写指令
  • 分支指令
  • 跳转指令

指令详解

算术运算指令

指令 格式 语法 描述
ADD R ADD RD,RS1,RS2 RS1和RS2的值相加，结果保存到RD
SUB R SUB RD,RS1,RS2 RS1的值减去RS2的值，结果保存到RD
ADDI I ADDI RD,RS1,IMM RS1的值和IMM（12位）相加，结果保存到RD
LUI U LUI RD,IMM RD的高20位存放IMM（20位），低12位清零
AUIPC U AUIPC RD,IMM 高20位为IMM（20位），低12位清零，与PC相加后放入RD
伪指令 语法 等价指令 描述
LI LI RD,IMM LUI和ADDI的组合 将32位立即数存放到RD中
LA LA RD,LABEL AUIPC和ADDI的组合 为RD加载一个地址值
NEG NEG RD,RS SUB RD,x0,RS 对RS中的值取反并存放到RD中
MV MV RD,RS ADDI RD,RS,0 将RS中的值拷贝到RD中
NOP NOP ADDI x0,x0,0 什么也不做

逻辑运算指令

指令 格式 语法 描述
AND R AND RD,RS1,RS2 RD = RS1 & RS2
OR R OR RD,RS1,RS2 RD = RS1 | RS2
XOR R XOR RD,RS1,RS2 RD = RS1 ^ RS2
ANDI I ANDI RD,RS1,IMM RD = RS1 & IMM
ORI I ORI RD,RS1,IMM RD = RS1 | IMM
XORI I XORI RD,RS1,IMM RD = RS1 ^ IMM
伪指令 语法 等价指令 描述
NOT NOT RD,RS XORI RD,RS,-1 对RS的值按位取反，结果存放在RD中

移位运算指令

指令 格式 语法 描述
SLL R SLL RD,RS1,RS2 RD = RS1 << RS2（逻辑）
SRL R SRL RD,RS1,RS2 RD = RS1 >> RS2（逻辑）
SLLI I SLLI RD,RS1,IMM RD = RS1 << IMM（逻辑）
SRLI I SRLI RD,RS1,IMM RD = RS1 >> IMM （逻辑）
SRA R SRA RD,RS1,RS2 RD = RS1 >> RS2（算术）
SRAI I SRAI RD,RS1,IMM RD = RS1 >> IMM（算术）

内存读写指令

内存读

指令 格式 语法 描述
LB I LB RD,IMM(RS1) 从内存RS1+IMM的位置中读一个8bit数据，符号拓展后保存到RD
LBU I LBU RD,IMM(RS1) 从内存RS1+IMM的位置中读一个8bit数据，零拓展后保存到RD
LH I LH RD,IMM(RS1) 从内存RS1+IMM的位置中读一个16bit数据，符号拓展后保存到RD
LHU I LHU RD,IMM(RS1) 从内存RS1+IMM的位置中读一个16bit数据，零拓展后保存到RD
LW I LW RD,IMM(RS1) 从内存RS1+IMM的位置中读一个32bit数据

内存写

指令 格式 语法 描述
SB S SB RS2,IMM(RS1) 将RS2寄存器中低8bit数据写入到内存RS1+IMM处
SH S SH RS2,IMM(RS1) 将RS2寄存器中低16bit数据写入到内存RS1+IMM处
SW S SW RS2,IMM(RS1) 将RS2寄存器中低32bit数据写入到内存RS1+IMM处

条件分支指令

指令 格式 语法 描述
BEQ B BEQ RS1,RS2,IMM 若RS1==RS2,则跳转到PC+IMM*2的位置
BNE B BNE RS1,RS2,IMM 若RS1!=RS2,则跳转到PC+IMM*2的位置
BLT B BLT RS1,RS2,IMM 若RS1<RS2（有符号）,则跳转到PC+IMM*2的位置
BLTU B BLTU RS1,RS2,IMM 若RS1<RS2（无符号）,则跳转到PC+IMM*2的位置
BGE B BGE RS1,RS2,IMM 若RS1>=RS2（有符号）,则跳转到PC+IMM*2的位置
BGEU B BGEU RS1,RS2,IMM 若RS1>=RS2（无符号）,则跳转到PC+IMM*2的位置
伪指令 语法 等价指令 描述
BLE BLE RS,RT,OFFSET BGE RT,RS,OFFSET 若RS<=RT（有符号）,则跳转到OFFSET的位置
BLEU BLEU RS,RT,OFFSET BGE RT,TS,OFFSET 若RS<=RT（无符号）,则跳转到OFFSET的位置
BGT BGT RS,RT,OFFSET BLT RT,RS,OFFSET 若RS>RT（有符号）,则跳转到OFFSET的位置
BGTU BGTU RS,RT,OFFSET BLTU RT,RS,OFFSET 若RS>RT（无符号）,则跳转到OFFSET的位置
BEQZ BEQZ RS,OFFSET BEQ RS,x0,OFFSET 若RS==0,则跳转到OFFSET的位置
BNEZ BNEZ RS,OFFSET BNE RS,x0,OFFSET 若RS!=0,则跳转到OFFSET的位置
BLTZ BLTZ RS,OFFSET BLT RS,x0,OFFSET 若RS<0,则跳转到OFFSET的位置
BLEZ BLEZ RS,OFFSET BGE x0,RS,OFFSET 若RS<=0,则跳转到OFFSET的位置
BGTZ BGTZ RS,OFFSET BLT x0,RS,OFFSET 若RS>0,则跳转到OFFSET的位置
BGEZ BGEZ RS,OFFSET BGE RS,x0,OFFSET 若RS>=0,则跳转到OFFSET的位置

无条件跳转指令

指令 格式 语法 描述
JAL J JAL RD,LABEL 将PC存到RD中，并跳转到PC+IMM*2的位置
JALR I JALR RD,IMM(RS1) 将PC存到RD中，并跳转到(RS1+IMM)%2的位置
伪指令 语法 等价指令 描述
J J OFFSET JAL x0,OFFSET 直接跳转到OFFSET处
JR JR RS JALR x0,0(RS) 直接跳转到RS处

编程约定（ABI:Abstract Binary Interface）

寄存器

寄存器名 ABI名 含义 维护者
x0 zero 常数0 N/A
x1 ra 返回地址 Caller
x2 sp 栈指针 Callee
x3 gp 全局指针
x4 tp 线程指针
x5 t0 临时寄存器 Caller
x6 t1 临时寄存器 Caller
x7 t2 临时寄存器 Caller
x8 s0/fp 保存寄存器/帧指针 Callee
x9 s1 保存寄存器 Callee
x10 a0 参数/返回值 Caller
x11 a1 参数/返回值 Caller
x12 a2 参数 Caller
x13 a3 参数 Caller
x14 a4 参数 Caller
x15 a5 参数 Caller
x16 a6 参数 Caller
x17 a7 参数 Caller
x18 s2 保存寄存器 Callee
x19 s3 保存寄存器 Callee
x20 s4 保存寄存器 Callee
x21 s5 保存寄存器 Callee
x22 s6 保存寄存器 Callee
x23 s7 保存寄存器 Callee
x24 s8 保存寄存器 Callee
x25 s9 保存寄存器 Callee
x26 s10 保存寄存器 Callee
x27 s11 保存寄存器 Callee
x28 t3 临时寄存器 Caller
x29 t4 临时寄存器 Caller
x30 t5 临时寄存器 Caller
x31 t6 临时寄存器 Caller
  • 参数0: 读取时总为0，写入无效
  • 返回地址：保存函数的返回地址，若多次调用，则调用者需要先保存原来的值
  • 栈指针：栈顶指针
  • 全局指针：加速对全局变量的访问
  • 线程指针：线程局部存储的指针
  • 临时寄存器：任何程序对其的使用是随意的，故若其中的值有用，则在调用的时候需要将其保存
  • 保存寄存器：Callee需要保证这些寄存器的值在函数返回后仍然是函数调用前的值，故Callee若使用，则需要先进行保存，在使用完成后进行恢复，其中s0常被用于帧指针（指向当前函数的栈帧基址
  • 参数寄存器：用于传递参数，其中a0和a1可以用于函数返回时传递返回值

函数跳转和返回指令

伪指令 等价指令 描述
jal offset jal x1,offset 跳转到offset指定位置，并将当前pc值保存在x1
jalr rs jalr x1,0(rs) 跳转到rs指定位置，并将当前pc值保存在x1
j offset jal x0,offset 跳转到offset指定位置，不保存当前pc值
jr rs jalr x0,0(rs) 跳转到rs指定位置，不保存当前pc值
call offset auipc x1,offset[31:12] + offset[11]
jalr x1,offset[11:0](x1)		 长跳转调用函数
tail offset auipc x1,offset[31:12] + offset[11]
jalr x0,offset[11:0](x6)		 长跳转尾调用
ret jalr x0,0(x1) 从Callee返回
